# ロシア語単語帳（Слова́рь）

ウズベキスタン旅行とロシア語の学び直しのための、フラッシュカード型 Web アプリです。
サーバー不要の静的サイトで、GitHub Pages で公開できます。iPhone のホーム画面に追加するとアプリのように使え、一度開けばオフラインでも動きます。

## 機能

- カード表示：ロシア語（アクセント記号付き・強勢母音を色付け）→ タップで日本語訳・例文
- 出題方向の切替：露→日 / 日→露（学習記録は方向ごとに別管理）
- 間隔反復：「覚えた／あいまい／忘れた」で次回出題日を調整（SM-2 を簡略化したもの）
- 音声読み上げ：ブラウザの音声合成（ru-RU）、速度・声を選べる
- カテゴリ絞り込み、単語一覧と検索、自由練習モード（記録しない）
- 学習記録は localStorage に保存、JSON でバックアップ・復元できる

## ファイル構成

```
index.html            画面
style.css             デザイン
app.js                アプリ本体
data/words.json       単語データ ← 単語はここに追加
sw.js                 オフライン用 Service Worker
manifest.webmanifest  ホーム画面追加用の設定
icons/                アイコン
```

## 公開手順（GitHub Pages）

1. このブランチを `main` にマージする（または Pages の公開元にこのブランチを指定する）
2. GitHub のリポジトリページで **Settings → Pages** を開く
3. **Build and deployment** の Source を **Deploy from a branch** にする
4. Branch を `main`、フォルダを `/ (root)` にして **Save**
5. 1〜2分で `https://<ユーザー名>.github.io/russian-flashcards/` に公開される

> 無料プランではリポジトリを **Public** にする必要があります（Private で Pages を使うには有料プランが必要）。

### iPhone のホーム画面に追加

1. iPhone の Chrome で公開 URL を開く
2. アドレスバー右の **共有ボタン（□↑）** →「**ホーム画面に追加**」
3. ホーム画面のアイコンから起動すると全画面のアプリとして開く

※ ホーム画面版の学習記録は、ブラウザで開いた場合とは別に保存されます。以降はホーム画面のアイコンから使ってください。

### 音声が出ないとき

- 消音モード（本体横のスイッチ）を解除する
- 「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → ロシア語」で声（Milena など）をダウンロードする
- アプリの「設定」タブで声を選び直し、テスト再生する

## 単語の追加方法

`data/words.json` に1行1語で追加します。GitHub のサイト上でファイルを開き、鉛筆アイコン（Edit）から直接編集して Commit すれば、数分後にアプリに反映されます。

```json
[
  {"id": "greet-01", "cat": "挨拶", "ru": "Здра́вствуйте", "ja": "こんにちは（丁寧）", "ex_ru": "Здра́вствуйте! Мо́жно вопро́с?", "ex_ja": "こんにちは！質問してもいいですか？", "note": "どの時間帯でも使える丁寧なあいさつ"},
  {"id": "my-001", "cat": "観光", "ru": "мече+ть", "ja": "モスク", "ex_ru": "Где мече+ть?", "ex_ja": "モスクはどこですか？"}
]
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `ru` | ○ | ロシア語 |
| `ja` | ○ | 日本語訳 |
| `id` | 推奨 | 他と重ならない ID（例 `my-001`）。学習記録はこの ID で管理されるので、**一度付けたら変えない**。省略するとロシア語の綴りが ID になる |
| `cat` | | カテゴリ名。新しい名前を書くとカテゴリが自動で増える |
| `ex_ru` / `ex_ja` | | 例文とその訳 |
| `note` | | 補足メモ |

### アクセント記号の入れ方

- **簡単な方法**：アクセントのある母音の直後に `+` を書く → `мече+ть` は `мечéть` と表示される
- 本来の結合文字（U+0301）をそのまま入れても OK（`Здра́вствуйте`）
- 1音節の単語と `ё` を含む単語は記号不要

### 書式の注意

- 各行の間は `,`（カンマ）で区切る。**最後の行の後ろにはカンマを付けない**
- 文字列は半角の `"` で囲む
- 書式を間違えるとアプリに「単語データを読み込めませんでした」と表示されます。[JSONLint](https://jsonlint.com/) などで確認できます

### 反映されないとき

アプリはオフライン用にデータをキャッシュしていますが、ネットにつながっていれば起動時に最新版を取りに行きます。反映されない場合はアプリを完全に閉じて開き直してください。

`app.js` や `style.css` などアプリ本体を変更したときは、`sw.js` 冒頭の `CACHE = 'rf-v1'` の番号を上げると確実に更新されます。

## ローカルで確認する

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く（PC ではスペースで答え表示、1/2/3 で評価、s で読み上げ）
```
